# 0006 — Go for server and agent

- Status: accepted
- Date: 2026-11-05

## Decision
Go (latest stable, currently 1.27) for every binary in one module. Agent and helper are built with `CGO_ENABLED=0` as static binaries. Agent code never imports `internal/server/...` and vice versa; shared code lives in `internal/common` and `internal/pki`.

## Consequences
Static binaries with zero runtime dependencies on managed hosts (agent ≈ 14 MB stripped, ≈ 18 MB RSS measured), first-class TLS/crypto/gRPC, one toolchain. The agent budget is enforced by `make agent-bench` in CI.
